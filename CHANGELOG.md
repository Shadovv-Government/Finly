# Changelog

## [0.5.0] — Pro Analytics & Unified Screen

### Аналитика (`Analytics.tsx`, `PremiumAnalytics.tsx`)
- **Единый экран аналитики** — базовый и Pro-контент на маршруте `/analytics` с переключателем вкладок «Базовая | Pro». Отдельный маршрут `/premium` также продолжает работать для прямого доступа к Pro-аналитике.
- **Встроенный Pro-апселл** — незарегистрированным пользователям показывается компактный `ProUpsellCompact` прямо внутри вкладки: фиолетовый hero, сетка 15 функций (иконка + название), кнопка «Получить Pro».
- **Period picker для Pro** — выбор периода (Месяц / Квартал / Год) встроен в Pro-вкладку; скрывается автоматически при переходе на подвкладку AI (как в прежнем standalone-экране).

### Брендинг
- **Переименование Premium → Pro** — все пользовательские надписи («Premium», «Получить Premium») заменены на «Pro» / «Получить Pro».
- **Цвет акцента amber → violet** — золотой цвет в Pro-контексте (спиннер `PremiumGate`, кнопки, иконка Crown) заменён на `violet-600` / `#7c3aed`. Фиолетовый градиент шапки и кнопок оставлен без изменений.

## [0.4.0] — Base Functionality Upgrade

### Аналитика (`Analytics.tsx`)
- **Полоса метрик** — под 3 сводными карточками появилась сетка 2×2 с метриками: средний расход/день, количество операций за период, крупнейший расход, норма сбережений (% от дохода).
- **Диаграмма структуры доходов** — новый pie-chart «Структура доходов» аналогично диаграмме расходов, с разбивкой по категориям и топ-5 списком.

### Дашборд (`Dashboard.tsx`)
- **Chip нормы сбережений** — на карточке баланса отображается цветной чип «↑ N% сбережений» / «↓ N% сбережений» (зелёный/красный).
- **Секция предстоящих платежей** — отображает до 4 регулярных платежей в ближайшие 7 дней с метками «Сегодня», «Завтра», «Через N дн.»; срочные (сегодня/завтра) выделены красным.

### История операций (`TransactionHistory.tsx`)
- **Полоса итогов при фильтрации** — при активных фильтрах под счётчиком «Найдено: N операций» появляются цветные плашки с суммой доходов и расходов в выборке.
- **Дублирование транзакции** — кнопка «Дублировать» в форме редактирования создаёт копию операции с текущими значениями полей.

### Бюджеты (`Budgets.tsx`)
- **Дневной остаток** — в каждой карточке бюджета рядом с суммой остатка показывается `≈ N₽/день` (остаток, делённый на дни до конца периода).

### Регулярные платежи (`RecurringScreen.tsx`)
- **Бейдж «Сколько осталось»** — на каждом активном шаблоне отображается бейдж: «Сегодня!» / «Завтра» / «Через N дн.». Срочные (≤1 день) выделены красным фоном.

### Настройки (`Settings.tsx`, `SettingsContext.tsx`)
- **Раздел «Статистика»** — новая секция в настройках показывает: количество операций, категорий, целей и дату первой записи. Данные загружаются из IndexedDB при монтировании.
- **Уведомления сохраняются** — 4 переключателя (Push, Бюджеты, Цели, Регулярные) теперь персистированы в localStorage через `usePersistentBool`.
- **Удалена мёртвая кнопка валюты** — строка «Валюта RUB (₽)» больше не содержит кнопку без обработчика.
- **`window.confirm` заменён на `AlertDialog`** — диалог выхода из аккаунта теперь работает в PWA standalone на iOS.

### Экран блокировки (`LockScreen.tsx`)
- **`window.confirm` заменён на `AlertDialog`** — кнопка сброса биометрии после 3 неудачных попыток использует Radix AlertDialog вместо нативного confirm.

### Категории (`Categories.tsx`)
- **Сортировка по использованию** — обе сетки (расходы и доходы) отсортированы по частоте использования в транзакциях.

### Цели (`Goals.tsx`)
- **Кнопка «Завершить цель»** — при 100% вместо задисейбленной кнопки «Пополнить» появляется зелёная «Завершить цель».
- **Секция завершённых целей** — цели с `isActive: false` показаны в блоке «Достигнуто» с трофеем и полупрозрачным оформлением.

### Повторяющиеся платежи — переименование
- Заголовок экрана: «Повтор» → «Регулярные платежи».
- Быстрая ссылка на дашборде: «Повтор» → «Регулярные».

## [0.3.0] — Premium Analytics

### Добавлено
- Premium-раздел `/premium` с 4 вкладками: Прогнозы, Сравнения, Здоровье, AI
- PremiumGate с paywall (PremiumUpsell) и списком 15 функций
- ML-прогноз расходов на 30 дней (линейная регрессия, CI-полосы, R²)
- Прогноз баланса на 3 месяца (cash flow AreaChart)
- What-If симулятор (Radix Slider, пресеты 50/30/20 и −20%)
- Эффект малых привычек (проекция регулярных трат)
- Расходы по дням недели (BarChart)
- Год к году (YoY сравнение, горизонтальный BarChart)
- Бюджет vs Факт (прогрессбары с цветовым статусом)
- Календарный heatmap (весь год, тепловая палитра)
- Топ-10 крупнейших транзакций
- STL-декомпозиция тренда (тренд + сезонность + остаток)
- Financial Health Score (6 метрик, полукруговой gauge, drilldown)
- Прогноз достижения целей (GoalsTimeline, ETA)
- AI-инсайты (авто-карточки, полный чат, еженедельный отчёт)
- Period picker: Месяц / Квартал / Год для всех вкладок
- Полная офлайн-поддержка (все данные из IndexedDB)

### Исправлено
- `avgMonthlyExpenses` в PredictiveTab некорректно рассчитывался для периодов 3м/1г (делил баланс текущего месяца на кол-во дней периода). Исправлено: используется `getBalanceByPeriod(start, end)` для всего выбранного периода.
- Анимации появления элементов на экране Premium Analytics были быстрее, чем на остальных экранах. Унифицировано через `Math.min` каппинг в `sectionVariants` и `cardVariants`.

## [0.2.0] — AI Assistant & Receipt Scanner

### Добавлено
- AI-чат ассистент с контекстом финансов пользователя (онлайн через OpenRouter)
- Офлайн-fallback на локальный NLP-движок (15+ intent-обработчиков)
- Сканирование чеков: QR-код (BarcodeDetector + jsQR), AI Vision (Gemini/Claude), OCR (Tesseract.js)
- TF.js ML-классификатор категорий с MC Dropout (24 признака, 5 уровней)
- Background Sync для фонового дообучения модели
