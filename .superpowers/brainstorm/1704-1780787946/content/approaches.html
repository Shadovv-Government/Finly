3 Подхода к Премиум-Аналитике

Выберите архитектурный подход — или предложите гибрид

A

Premium Dashboard — Отдельный Экран

Новый экран PremiumAnalytics.tsx, доступный только после покупки. Все 3 категории фич на одном экране с вкладками.

Плюсы

  • Чёткий водораздел free/premium
  • Легко продавать ценность
  • Код изолирован, не ломает бесплатное

Минусы

  • Два разных экрана аналитики
  • Возможное дублирование данных
B

Integrated — Расширение Существующей Аналитики

Премиум-секции встраиваются в текущий Analytics.tsx, разблокируются по флагу premium.

Плюсы

  • Единый опыт аналитики
  • Нет дублирования

Минусы

  • Смешивание кода
  • Сложнее тестировать
  • Раздувается файл
C

AI Insights Hub — AI-Центричный

Новый экран с AI-финансовым ассистентом, который генерирует персональные инсайты, прогнозы и отчёты на естественном языке.

Плюсы

  • Сильный дифференциатор
  • Использует существующий AI-стек
  • "Вау-эффект"

Минусы

  • Требует интернет для AI-части
  • Дороже в эксплуатации (API)

Моя рекомендация: A + C (Гибрид)

Отдельный PremiumAnalytics экран с тремя вкладками (Прогнозы, Сравнения, Health Score) + AI-инсайты как сквозная функция. Большинство данных считается локально (ML), AI генерирует только текстовые инсайты по запросу — через существующий OpenRouter прокси.
