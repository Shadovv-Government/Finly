Premium Gate — Как Защитить Доступ

Механика разовой покупки
  1. AppSettings в IndexedDB хранит флаг premium: true
  2. PremiumGate компонент — обёртка, проверяет флаг перед рендером
  3. Без флага: показывает PremiumUpsell с описанием фич и кнопкой покупки
  4. Платёж через Telegram Stars / DonationAlerts / прямой платёж (TBD)
  5. После оплаты: серверный webhook → флаг premium: true в IndexedDB
  6. Восстановление: импорт флага при переносе данных (экспорт/импорт JSON)
