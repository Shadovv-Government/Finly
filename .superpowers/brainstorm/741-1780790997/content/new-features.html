⚙️ Улучшение
Выбор периода для всей аналитики
Сегментед-контрол в шапке: «Месяц / Квартал / Год». Все три вкладки переключаются вместе. Сейчас всё захардкожено на текущий месяц.
[ Месяц ] [ Квартал ] [ Год ] ↑ выбрано → все графики пересчитываются
Сложнее — рефакторинг data-fetching во всех вкладках
⚙️ Улучшение WhatIf
Сценарии + кнопка сброса в симуляторе
Кнопка «Сбросить всё» + пресетные сценарии: «Правило 50/30/20», «Режим экономии −20%», «Откладываю X₽ в месяц». Делает симулятор живым.
[ Правило 50/30/20 ] [ −20% везде ] [ Сброс ] — применяет значения слайдеров одним кликом
Лёгко — только UI поверх готового симулятора
⚙️ Улучшение HealthTab
Кликабельные метрики здоровья
Сейчас метрики — просто полоски. По клику → sheet с объяснением: «Что это?», «Ваш показатель: X», «Как улучшить?» с конкретными шагами.
📊 Норма сбережений 72/100 → [нажал] ┌─ Что это? Доля дохода которую вы сберегаете │ Ваш показатель: 15% (норма: 20%+) │ Как улучшить: Автоматически откладывать... └────────────────────────────────────────────
Средне — bottomsheet с контентом на каждую метрику
✨ Новая фича
«Эффект кофе» — маленькие траты × год
Находит регулярные небольшие траты (кафе, подписки) и показывает: «Вы тратите 350₽/день на кофе → 127 750₽ в год». Wow-moment который врезается в память.
☕ Кофе/кафе: 350 ₽/день → 2 450 ₽/нед → 127 750 ₽/год → хватило бы на: 8.5 мес. отпуска
